# Memory Gallery Photos (images/)

## Ready-to-use Placeholders
This folder currently contains 12 high-resolution, luxury fairytale aesthetic illustrations:
- `photo1.jpg` to `photo12.jpg`

## How to use your own photos:
1. Copy your personal photos into this `images/` directory.
2. Name them `photo1.jpg`, `photo2.jpg`, `photo3.jpg`, etc. up to `photo100.jpg`.
3. Open `script.js` and edit the `CONFIG.gallery` and `CONFIG.timeline` lists with your own captions, dates, and titles!
